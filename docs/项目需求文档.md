项目名：可编排多工具销售任务拆解 Agent


核心定位：
自主拆解销售全流程子任务、调度多数据源工具、内置 RAG 事实验真反思机制、标准化 JSON 输出对接企业 CRM 系统，
支持云端大模型 (OpenAI)、本地私有化 Qwen 双部署模式，基于 Python+LlamaIndex Agent 框架搭建。


一、项目完整需求拆解（业务 + 功能 + 非功能）
1.1 业务场景详细定义（CRM 销售全链路）
面向 B2B 实体产品销售场景，客户线上 / 线下发起咨询（批量拿货、设备采购、询价、定制方案需求），替代传统销售手动查库存、翻历史订单、找成交案例、手动算报价的重复工作：
1. 客户输入需求示例：「采购 50 台工业风机，想要 30 天账期，对比往期大客户成交价，给一套合作方案」
2. Agent 自动拆解 4 个强制串行 / 可并行子任务：
任务 1：接口查询工具 → 调取 CRM 库存接口，核实 50 台风机实时库存、备货周期；
任务 2：数据库查询工具 → 读取 SQL 成交库，提取同规格风机近 6 个月不同采购量历史成交价、账期政策；
任务 3：文档检索工具 (LlamaIndex RAG) → 检索本地成交案例文档库，匹配采购量 40–60 台、账期 20–40 天的相似客户完整合作案例；
任务 4：计算器工具 → 根据采购数量、基准单价、阶梯折扣、账期资金成本自动核算最终报价、毛利区间；
3. 反思校验环节（复刻纷享「工程验真」RAG 策略）：拦截大模型凭空编造库存、价格、案例数据，提取 Agent 输出内所有事实字段，反向比对 SQL 库、向量文档库做二次核验，标记幻觉并自动修正；
4. 最终输出固定结构 JSON，可直接推送至企业 CRM、企业微信、ERP 系统，无需人工二次格式调整。
1.2 核心功能需求
1. 双大模型兼容：一键切换 OpenAI 云端 API / Ollama 本地 Qwen（Qwen-7B/14B）；
2. 可编排多工具调度：支持自定义任务串行、并行执行，后续可新增物流查询、资质审核等工具；
3. 智能任务拆解器：大模型根据客户咨询文本自主拆分标准化子任务队列；
4. 事实反思校验引擎：分层 RAG 验真，量化幻觉风险；
5. 强约束提示词角色锁死：严格限定 Agent 仅作为销售数据助理，禁止无工具编造信息；
6. Pydantic 强 Schema 约束输出，100% 固定 JSON 格式；
7. 对外暴露 FastAPI 接口，适配企业内部系统调用；
8. 全链路日志：记录任务拆解记录、每一步工具返回值、反思校验日志、幻觉修正记录。
1.3 非功能工程化需求（区分玩具代码与企业可用系统）
1. 数据安全：本地 Qwen 模式所有客户数据、报价文档不出服务器；云端模式密钥环境变量隔离，禁止硬编码；
2. 可扩展性：新增工具仅需实现统一工具基类，无需改写 Agent 主流程；
3. 稳定性：工具调用超时、接口宕机、向量库加载失败具备降级容错；
4. 可观测：完整日志、每个子任务耗时打点；
5. 可测试：全链路单元测试、工具独立测试、幻觉场景专项测试；
6. 易部署：Docker 一键打包本地私有化服务、云服务器容器部署两种方案。


二、整体业务时序逻辑（正常 + 异常流程）
标准完整执行时序
1. 上游 CRM 系统 / 前端页面 POST 传入客户咨询文本、客户 ID、产品品类；
2. 请求入口层做入参清洗、基础格式校验；
3. Agent 任务拆解器基于系统提示词，输出结构化任务列表（库存查询 / 价格查询 / 案例检索 / 报价计算）；
4. 调度引擎分发任务至对应工具，同步获取原始真实数据；
5. 原始数据送入纷享式工程验真反思模块：
① 抽取待生成方案内所有事实实体（库存数量、单价、案例编号、折扣比例）；
② 多源数据源二次匹配核验（SQL 价格库、Chroma 向量案例库、库存 API）；
③ 识别幻觉字段、标注置信度，自动修正错误数值；生成独立反思报告；
6. 大模型依托校验后的真实数据源撰写定制销售沟通方案；
7. 通过 Pydantic Schema 强制格式化输出标准 JSON；
8. API 接口返回 JSON 结果 + 完整任务日志 + 反思校验报告；同步落盘日志文件。
异常兜底流程
1. 某工具接口超时：标记任务失败，Agent 自动生成「数据缺失提示」，方案中标注哪部分数据无法获取，不编造填充；
2. 反思校验发现高比例幻觉：终止方案生成，返回错误状态码 + 幻觉明细；
3. 客户需求模糊无法拆解任务：返回标准化提示，引导补充产品、采购量关键信息；
4. 本地 Qwen 模型显存不足：自动降级调用小参数模型或切换云端 OpenAI 备用线路。


三、系统分层架构（企业解耦四层架构）
【接入层 FastAPI】 ←→ 【SalesAgent核心编排层】 ←→ 【工具服务层】 ←→ 【存储&大模型基础设施层】

分层详细职责
1. 接入层
对外 HTTP 接口、入参校验、跨域、请求鉴权、流量入口；对接前端、企业 CRM/ERP。
2. 核心编排层（项目重心）
◦ LLM 适配适配器：统一封装 OpenAI / Ollama-Qwen 调用，对外一致入参；
◦ TaskPlanner 任务拆解器：大模型驱动拆分销售子任务队列；
◦ ToolDispatcher 调度器：编排串行 / 并行工具执行顺序；
◦ ReflectionEngine 反思验真引擎：复刻纷享工程验真 RAG 校验逻辑；
◦ SalesAgent 主调度类：串联全流程，组装数据源生成销售方案；
◦ Schema 格式化器：强制约束输出 JSON 结构。
3. 工具服务层（可插拔多工具）
统一抽象工具基类，四大内置工具：
◦ CalculatorTool：高精度数值计算（阶梯报价、毛利、账期成本）；
◦ ApiQueryTool：CRM 库存 HTTP 接口查询；
◦ SqlPriceTool：本地 SQLite/MySQL 历史成交价查询；
◦ DocRetrieveTool：LlamaIndex+Chroma 向量库成交案例文档检索；
后续新增物流、资质、回款测算工具只需继承基类，无侵入改动主逻辑。
4. 基础设施存储层
◦ LLM 服务：云端 OpenAI API / 本地 Ollama Qwen 模型；
◦ 结构化存储：SQLite（产品基础信息、历史成交订单）；
◦ 向量存储：Chroma（存放 PDF/Markdown 成交案例、销售话术文档，RAG 检索）；
◦ 配置层：.env 环境变量、全局参数；日志持久化文件。


四、全维度技术栈明细（每个组件写明实现作用）
模块分区	技术选型	核心实现功能 & 选型理由
主开发语言	Python3.10+	AI 生态最成熟，LlamaIndex、Ollama、FastAPI 完美适配，小白易上手调试
Agent 编排框架	LlamaIndex Agent	原生支持工具调用、任务规划、RAG 深度融合；对比原生 OpenAI Agent 优势：天然兼容本地开源 Qwen 模型，RAG 验真逻辑更容易嵌入反思流程
大模型双底座	1. 云端：OpenAI gpt-3.5-turbo2. 本地：Qwen-7B/14B（Ollama 部署）	兼顾两种企业需求：中小企业用云端降成本；涉密制造企业本地私有化，数据不出内网；统一调用适配器无缝切换
工具体系	自定义继承 LlamaIndex BaseTool	统一入参、出参格式，调度器批量管理；四大业务工具：计算器、库存接口、SQL 价格查询、文档向量检索
反思验真 RAG	LlamaIndex Retriever + 自定义校验引擎（纷享工程验真复刻）	不单纯靠大模型自省，用真实数据库 / 向量库做事实硬校验，从数据源层面压低幻觉率
接口服务	FastAPI	异步高并发、自动生成接口文档、适配企业系统对接，AI 行业后端标准选型
结构化数据库	SQLite（开发）/ MySQL（生产）	存储产品基础信息、历史成交订单、客户档案；轻量无部署门槛，生产可无缝迁移 MySQL
向量数据库	Chroma	轻量本地向量库，无需额外部署服务，存储成交案例文档；适配私有化本地部署场景
数据格式约束	Pydantic v2	强类型定义输入输出 JSON Schema，杜绝格式错乱，直接匹配 CRM 系统字段
提示词工程	分层系统 Prompt（角色层 / 任务规则层 / 输出约束层）	三层约束锁定 Agent 行为：禁止编造数据、强制拆分四任务、严格 JSON 输出
测试体系	Pytest + requests	工具单测、接口自动化测试、幻觉场景专项测试、多模型兼容测试
部署打包	Docker + Ollama 容器化	本地私有化一键部署；云服务器直接运行容器；前后端分离独立打包
辅助组件	python-dotenv (配置隔离)、logging (全链路日志)、uvicorn (ASGI 服务)	工程化必备：密钥不硬编码、问题可追溯、高性能异步服务
