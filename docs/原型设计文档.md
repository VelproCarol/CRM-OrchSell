## 一、设计概述

### 1.1 设计目标

为 CRM-sale-Agent 系统设计三套前端界面，分别服务于不同用户角色：

| 页面 | 目标用户 | 核心目标 | 对应 API |
|------|----------|----------|----------|
| 销售咨询页面 | 销售顾问 | 快速生成可信销售方案 | POST /api/chat/sales |
| API 调试页面 | 系统管理员/开发 | 调试和验证所有接口 | 全部 9 个端点 |
| 管理后台 | 销售经理/管理员 | 管理数据、监控运行 | GET /api/stats, /api/health 等 |

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 简洁优先 | 销售顾问页面极简，一键生成方案 |
| 数据透明 | 每个数据字段可追溯来源 |
| 可信标识 | 反思验真结果可视化（置信度条/风险标签） |
| 响应式 | 适配桌面端为主，移动端可用 |
| 实时反馈 | 任务拆解、工具执行过程实时展示 |

### 1.3 技术约束

| 约束 | 说明 |
|------|------|
| 当前前端 | 单文件 HTML（frontend/index.html） |
| 输出格式 | Markdown 描述 + ASCII 线框图 |
| API 交互 | REST/JSON，异步请求 |
| 无前端框架 | 原生 HTML/CSS/JS 或轻量框架 |

### 2.4 交互流程

```
用户输入咨询 → 点击"生成销售方案"
    ↓
显示任务执行进度（4阶段）
    ├── 阶段1: 任务拆解（显示拆解出的任务列表）
    ├── 阶段2: 工具调度（实时更新每个任务状态: pending→running→completed）
    ├── 阶段3: 方案生成（等待中）
    └── 阶段4: 反思验真（等待中）
    ↓
方案生成完成 → 展示结果区域
    ├── 库存信息卡片
    ├── 价格信息卡片
    ├── 相似案例列表
    ├── 销售方案（7字段）
    ├── 反思验真报告（置信度+校验状态）
    ├── 客户画像（折叠）
    └── 跟进记录（折叠）
    ↓
用户可操作: 导出PDF / 转发微信 / 复制JSON / 重新生成
```

### 2.5 状态展示规则

| 状态 | 视觉表现 | 含义 |
|------|----------|------|
| success | ✅ 绿色 | 数据可信，验真通过 |
| partial | ⚠️ 黄色 | 部分数据不可信或降级方案 |
| error | ❌ 红色 | 请求失败 |
| pending | ⬜ 灰色 | 任务等待执行 |
| running | ⏳ 蓝色动画 | 任务执行中 |
| completed | ✅ 绿色 | 任务完成 |

### 2.6 置信度可视化

```
置信度 ≥0.9:  ████████████████████  优秀  ✅
置信度 0.8-0.9: ████████████████░░░░  良好  ✅

置信度 <0.6:   ████████░░░░░░░░░░░░  风险  ❌
```

## 六、交互流程汇总

### 6.1 销售咨询完整流程

```
开始
  ↓
[销售咨询页面] 输入咨询文本 + 选择客户/产品
  ↓
点击"生成销售方案"
  ↓
POST /api/chat/sales
  ↓
[任务执行进度] 实时展示4阶段进度
  ├── 阶段1: TaskPlanner 任务拆解 → 显示任务列表
  ├── 阶段2: ToolDispatcher 工具调度 → 实时更新任务状态
  ├── 阶段3: 方案生成 → 等待中
  └── 阶段4: 反思验真 → 等待中
  ↓
返回 SalesResponse
  ↓
[销售方案结果] 展示完整结果
  ├── 库存信息卡片
  ├── 价格信息卡片
  ├── 相似案例列表
  ├── 销售方案（7字段）
  ├── 反思验真报告
  ├── 客户画像（折叠）
  └── 跟进记录（折叠）
  ↓
用户操作: 导出PDF / 转发微信 / 复制JSON / 重新生成
  ↓
结束
```

### 6.2 API 调试流程

```
开始
  ↓
[API调试页面] 从侧栏选择接口
  ↓
自动填充 URL / 方法 / 请求体模板
  ↓
用户编辑请求参数
  ↓
点击"发送请求"
  ↓
HTTP 请求 → 等待响应
  ↓
展示: 状态码 / 耗时 / 响应大小
  ↓
切换标签: 格式化JSON / 原始数据 / 仅方案 / 仅反思
  ↓
请求记录保存到历史列表
  ↓
结束
```

### 6.3 管理后台流程

```
开始
  ↓
[管理后台] 登录 → 进入仪表盘
  ↓
查看运行概览（统计/趋势/模型分布/Token消耗）
  ↓
根据需要进入子页面:
  ├── 客户管理 → 查看/搜索客户 → 查看详情 → 查看跟进记录
  ├── 产品库存 → 查看库存 → 库存预警处理
  ├── 成交记录 → 查看历史成交 → 筛选/导出
  ├── 模型配置 → 切换模型 → 调整反思阈值
  └── 监控面板 → 查看Prometheus指标 → 查看LangFuse追踪
  ↓
结束
```
